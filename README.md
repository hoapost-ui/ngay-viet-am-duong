# Ngày Việt

Mini App quy đổi **dương lịch ↔ âm lịch Việt Nam** theo múi giờ UTC+7.

## Tính năng

- Đổi ngày dương sang ngày âm và ngược lại.
- Hỗ trợ tháng nhuận và kiểm tra ngày hợp lệ.
- Hiển thị thứ trong tuần, năm Can Chi và nút sao chép kết quả.
- Giao diện responsive cho điện thoại và máy tính.
- Chạy độc lập, không cần cơ sở dữ liệu hay API bên ngoài.

## Chạy và kiểm tra

```bash
npm test
npm run build
npm run validate
```

Mã Worker nằm tại `worker/index.js`. Bản đóng gói được tạo trong `dist/`.
